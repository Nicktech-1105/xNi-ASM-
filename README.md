# xNi Assembly Language SDK (xNI AL)
this is the official repository for xNi, this repository contains the following elements:

->28 example programs for xNi
->a transpiler (xNi/xNi binaries -> x86/ARM-64/ARM-32)
->an assembler (xNiASM/Nichrome -> xNi binaries) and dissaembler (xNi binaries -> xNiASM)
->a bootloader (28oot) if someone ever etches an xNi CPU
->some abstraction layers
->CPU and hardware desings (in Logisim and perhaps drawn directly on paper as well)
and last but not least: documentation for the ISA, the physical architecture and hardware, the programs included here, and other stuff i maybe forgot to mention in this brief piece of text.
