# xNi Assembly Language + SDK 


### this is the official repository for xNi, this repository contains the following elements:

->**28 example programs** for xNi\n
->**a transpiler** (xNi/xNi binaries -> x86/ARM-64/ARM-32)\n
->**an assembler** (xNiASM/Nichrome -> xNi binaries) and dissaembler (xNi binaries -> xNiASM)\n
->**an IDE** for xNi and Nichrome\n
->**a bootloader** (28oot) if someone ever etches an xNi CPU\n
->**some abstraction layers and T.R.E.S** (a basic command terminal written on xNi and Nichrome)\n
->**CPU and hardware desings** (in Logisim and perhaps drawn directly on paper as well)\n
and last but not least: documentation for the ISA, the physical architecture and hardware, the programs included here, and other stuff i maybe forgot to mention in this brief piece of text.
